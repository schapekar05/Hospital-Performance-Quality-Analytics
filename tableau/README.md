# Tableau Dashboards

This folder contains the Tableau dashboard plan and the screenshots exported from the completed workbook.

## Data source
Use the cleaned dataset created by the Python script:

`output/cleaned_hospitals.csv`

## Planned dashboards

1. **Hospital Overview** — total hospitals, states covered, hospitals by state, ownership mix and hospital type.
2. **Hospital Ratings** — overall rating distribution and rating mix by state.
3. **Hospital Services** — emergency services, hospital type and ownership.
4. **Data Quality** — missing values, rating coverage and duplicate facility identifiers.
