# Tableau dashboard plan

The Tableau workbook will use the cleaned CMS hospital-level CSV generated by `src/hospital_analysis.py`.

## Dashboard pages
1. Hospital Overview — KPI cards, hospitals by state, ownership mix and hospital type.
2. Hospital Ratings — rating distribution and rating mix by state.
3. Hospital Services & Profile — emergency services, ownership and hospital type.
4. Data Quality — missing values, rating coverage and duplicate identifiers.

## Filters
State, hospital type, hospital ownership and emergency services.

## KPI definitions
- Total hospitals: distinct facility IDs.
- States covered: distinct state values.
- Hospitals with rating: distinct facility IDs with a non-null overall rating.
- Rating coverage: hospitals with rating divided by total hospitals.
- Category percentage: category count divided by the relevant filtered denominator.

## Build and validation
Run the Python script first. Connect Tableau to `output/cleaned_hospitals.csv`. Validate KPI counts against the Python outputs and show the CMS source and extraction date.

Keep facility IDs as text. Treat missing ratings separately from rating values. Check CMS definitions and reporting periods before comparing quality measures. This is descriptive analysis, not causal analysis.
